## 1. Colossal Conversor とは？

Colossal Conversor は、音声・動画・画像・文書・表計算・プレゼンテーション
形式のファイルを変換するオフラインのデスクトップアプリケーションです。
すべての処理は C++20 ネイティブ実行コアによってローカルで完結します —
クラウドへのアップロードもアカウントも不要で、変換自体にネットワーク接続
は必要ありません。技術的な全体像については、メインの
[README](../../../README.md) を参照してください。

このガイドでは、インストール、初めての変換、バッチ処理とパイプラインの
使い方、問題が起きたときの対処法など、実際の日常的な使い方を扱います。

## 2. 対応プラットフォーム

Colossal Conversor は **macOS・Linux・Windows** を対象としています。
ネイティブのプロセス監視レイヤーはプラットフォームごとに専用のバックエンド
を持っており、プロセスの生成、出力の取得、キャンセル、後始末はどの環境
でも同じように動作します。

| プラットフォーム | 状態 |
|---|---|
| macOS | 検証済み — ビルド・テスト済みで、日常の開発にも使用 |
| Linux | 実装済み（macOS と同じバックエンドを使用）— Linux 環境での実機検証は未実施 |
| Windows | Windows のプロセス API に基づき実装済み — Windows 環境での実機検証は未実施 |

「実装済みだが未検証」とは、コードは存在し正しいプラットフォーム契約に
従って書かれているものの、そのプラットフォーム上で実際の変換が成功する
ことをまだ誰も確認していない、という意味です。検証が進み次第この記述は
更新されます — 現在の状況はメイン README の対応プラットフォームの節を、
Linux や Windows の検証に協力したい場合は
[CONTRIBUTING.md](../../../CONTRIBUTING.md) を参照してください。

## 3. インストール

Colossal Conversor 本体のインストールと、一部の変換で使用する外部ツール
のインストールは別物です（下記の「外部依存関係」を参照）。

### macOS / Linux

```bash
git clone https://github.com/sxnnyside-project/colossal-conversor.git
cd colossal-conversor
just install
just dev
```

### Windows

```powershell
git clone https://github.com/sxnnyside-project/colossal-conversor.git
cd colossal-conversor
just install
just dev
```

`just install` は Python の依存関係を同期し、ネイティブ拡張をビルドします。
`just dev` でアプリケーションを起動します。`just` をお持ちでない場合は
[インストール手順](https://github.com/casey/just#installation) を参照する
か、メイン README に記載の `uv sync --all-groups` とネイティブ CMake ビル
ドを直接実行してください。

## 4. 外部依存関係

一部の変換カテゴリは外部ツールを呼び出しますが、それ以外は完全にアプリ
内部で処理され、追加のツールは不要です。

| ツール | 必要な用途 |
|---|---|
| FFmpeg | 音声・動画の変換 |
| LibreOffice | 文書・表計算・スライドの変換 |
| Poppler (`pdftoppm`) | 文書 → 画像のページレンダリング |
| Pandoc | Markdown ↔ 文書の変換 |
| ImageMagick | BMP/PPM/TGA 以外の画像変換（これらはツール不要でネイティブ処理） |

現在利用可能なツールを確認するには:

```bash
just verify-tools
```

不足しているものをインストールするには:

- **macOS**: `bash tools/macos_install_deps.sh`（Homebrew）
- **Linux**: `bash tools/linux_install_deps.sh`（apt・dnf・pacman を自動検出）
- **Windows**: PowerShell で `tools/windows_install_deps.ps1` を実行（winget、または既にインストール済みなら Chocolatey）

これらのツールをインストールしただけでは、すべての変換が動作することを
保証するものではありません — 該当するエンジンが利用可能になるだけです。
アプリケーションは実行時に各ツールを検出し、実際に実行できる変換のみを
提示します。

## 5. 初めての変換

1. アプリを起動します（`just dev`）。
2. **Select File(s)** をクリックするか、ファイルを取り込みエリアにドラッグします。
3. Colossal Conversor は入力形式を検出し、実際に生成できる変換先の形式
   のみをカテゴリ別に表示します。
4. 変換先の形式をクリックします。
5. デフォルト以外の保存先にしたい場合は **Save As...** をクリックして
   選択（または確認）します。
6. **Convert** をクリック（または <kbd>Enter</kbd> キーを押す）します。

完了すると、生成されたファイル数を知らせるダイアログが表示され、結果を
開く、またはファイルマネージャーで表示するボタンが用意されています。

## 6. 複数ファイル

**Select File(s)** をクリックして複数のファイルを選択するか、複数ファイ
ルを一度にドラッグします。Colossal Conversor は選択したすべての入力に共
通する出力形式のみを表示します。**Save As...** で（単一ファイルではなく）
**フォルダ**を保存先として選び、**Convert** をクリックすると、各入力が
そのフォルダにそれぞれ出力を生成します。

## 7. マルチアウトプット変換

一部の変換は、1 つの入力から複数のファイルを生成します — 例えば PDF の
各ページを個別の画像としてレンダリングする場合です。これは選択した形式
の組み合わせによって自動的に検出され、選んだ保存先は生成されたすべての
ページを含むフォルダになります。完了ダイアログには実際に生成されたファ
イル数が表示されます。

## 8. パイプライン

一部の変換は 1 段階では完結せず、内部で自動的に複数の段階に分割されます
— 例えば、プレゼンテーションを画像に変換する場合、まず中間の PDF を経由
します。この設定は不要です。通常どおり入力と変換先の形式を選ぶだけで、
進捗バーには現在実行中の段階が表示されます。中間ファイルは、パイプライ
ンが完了（または失敗やキャンセル）した時点で自動的に削除されます。

## 9. 出力形式の選択

形式のグリッドには、Colossal Conversor が現在の入力から実際に生成できる
変換先のみが表示されます — 実行できない変換を宣伝することはありません。
形式を選択すると、「high」「medium」「layout」などの忠実度に関する注記
が表示され、出力が元のファイルをどの程度保持するかを示します。これは、
異なる能力を持つ形式間で変換する場合（例: スタイル付き文書からプレーン
テキストへの変換）に役立ちます。

## 10. 保存先の選択

**Save As...** で出力の保存先を選べます。単一出力の変換ではファイルパス
を、バッチまたはマルチアウトプット変換ではフォルダを選びます。明示的に
選択しない場合、アプリは入力ファイルのそばに適切なデフォルトの保存先を
提案します。

## 11. キャンセル

変換の実行中に **Cancel** をクリックすると、その変換を停止できます。こ
れは実際に基盤となるプロセスを終了させるものであり（単に UI の状態を変
えるだけではありません）、部分的な出力が成功した結果として報告されるこ
とはなく、ステータスバーには成功・失敗のいずれとも異なる「Conversion
cancelled」が表示されます。その直後に新しい変換を開始できます。

## 12. エラーとリカバリー

変換に失敗すると、ダイアログが平易な言葉で何が起きたかを説明し、基盤と
なる技術的な出力を確認するための **Show Details...** ボタンが表示されま
す（要求した場合のみ表示されます）。変換に失敗してもアプリケーションが
クラッシュしたりフリーズしたりすることはありません — ダイアログを閉じ、
必要に応じて入力・変換先の形式・保存先を調整して再試行してください。

## 13. 依存関係が見つからない場合

変換に必要なツールがインストールされていない場合、エラーメッセージには
そのことが明示され、ツール名も示されます — 一般的な失敗と混同されること
はありません。`just verify-tools` を実行して全体の状況を確認し、不足し
ているものをインストールする方法については上記の「外部依存関係」を参照
してください。

## 14. 対応形式

アプリケーション内の形式グリッドが、常に最新の正式なリストです — 変換
エンジンが使用するのと同じカタログから生成されるため、現在のビルドが実
際にできないことを宣伝することは決してありません。大まかに言うと、
Colossal Conversor は以下に対応しています:

- **音声**: MP3、WAV、FLAC、AAC、OGG などの一般的な形式。
- **動画**: MP4、MKV、MOV、AVI、WebM などの一般的な形式。
- **画像**: PNG、JPEG、WebP、BMP、TIFF、GIF などの一般的な形式。
- **文書**: DOC/DOCX、ODT、RTF、TXT、PDF、Markdown、HTML、EPUB。
- **表計算**: XLS/XLSX、ODS、CSV、TSV。
- **プレゼンテーション**: PPTX/PPT、ODP。

アプリケーション内で入力ファイルを選択すると、そのファイルに対する正確
で最新の変換先一覧が表示されます。

## 15. トラブルシューティング

**動作すると思っていた変換が表示されない。** 変換先の形式一覧は、選択し
た入力の検出された形式から生成されます — 入力が正しく検出されているか
（ファイル名の横に表示されます）、その形式の組み合わせに対して目的の変
換が実際にサポートされているかを確認してください。

**「依存関係が見つかりません」エラー。** `just verify-tools` を実行し、
表示されたツールをインストールしてください（上記の「外部依存関係」/
「依存関係が見つからない場合」を参照）。

**変換がすぐに失敗する。** エラーダイアログの **Show Details...** を確認
してください。よくある原因: 入力ファイルが壊れている、または読み取れな
い、あるいは検出された入力が実際にはその形式と一致しない（例: 拡張子が
間違ってリネームされたファイル）。

**Cancel を押しても見た目に何も起きない。** 非常に短い変換の場合、Cancel
が反映される前に処理が完了することがあります — これは想定内の動作であ
り、バグではありません。結果は通常の成功または失敗となり、UI が固まる
ことはありません。

**保存先のパスが無効。** フォルダが存在し、書き込み権限があることを確認
してください。単一ファイル出力の場合は、親フォルダが存在することを確認
してください。

**それでも解決しない場合。** issue を開いてください — [SUPPORT.md](../../../SUPPORT.md) を参照。
